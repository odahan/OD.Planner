OD.Planner

Version 1.3.0 - User Manual

Introduction

OD.Planner is a lightweight, Windows-native task planner built with WPF and .NET. It keeps your to-do list close at hand in a small, always-ready window and makes sure deadlines don't slip by — with audible alarms and color-coded urgency.

Getting Started

First Launch

When you first launch OD.Planner, you'll be asked to choose where to store your tasks database. By default, it's created next to the application executable. You can change this location later in Settings.

Main Window

The main window displays your task list with:

  • A category filter dropdown to show only tasks from a specific category
  • A checkbox to show/hide completed tasks
  • An "Add" button to create new tasks

Task Management

Creating a Task

Click the Add button or press Ctrl+N to create a new task. You'll be prompted to enter:

  • Title - The task description (required)
  • Category - Optional category for organization
  • Priority - Low, Medium, Urgent, or Very Urgent
  • Deadline - None, X days from creation, or a fixed date

Editing a Task

Select a task and press F2 or click the edit button to modify it.

Completing a Task

Click the checkbox next to a task to mark it as completed. Completed tasks can be hidden using the "Completed" checkbox.

Deleting a Task

Click the delete button next to a task. You'll be asked to confirm the deletion.

Deadlines & Alarms

Deadline Types

  • None - No deadline for this task
  • Days from creation - Deadline is X days after the task was created
  • Fixed date - Deadline is a specific date

Postponing Deadlines

Each task with a deadline shows +1j and +1sem buttons to postpone the deadline by 1 day or 1 week.

Alarm Levels

LevelTriggerIndicator
Attention (J-1)1 day before deadlineYellow chip
Due (J0)On the deadline dateOrange chip
OverdueAfter the deadlineRed chip + blinking

Alarm Popups

When an alarm triggers, a popup appears with options to:

  • Snooze 1h - Silence the alarm for 1 hour
  • Stop - Dismiss the alarm permanently

Categories

Categories help you organize tasks. You can create, rename, and delete categories in the Settings dialog.

Default categories: Travail (Work) and Personnel (Personal).

Settings

Click the gear icon to open Settings. Available options:

Appearance

  • Dark theme - Switch between light and dark themes
  • Show completed tasks - Toggle visibility of completed tasks
  • Reduce animations - Disable blinking animations for accessibility

Sound Alarms

  • Enable sound alarms - Master switch for all sound alerts
  • J-1 alert - Sound alert the day before deadline
  • J0 alert - Sound alert on the deadline day
  • Overdue alert - Sound alert when overdue

System

  • Start with Windows - Launch OD.Planner at system startup

Database

Change the location of your tasks database file. The application will use the new location after restart.

Data Storage

Tasks are stored in a SQLite database (tasks.db). Settings are saved as settings.json. Both files are located next to the application by default, or under %LOCALAPPDATA%\OD.Planner if the app folder is not writable.

Note: You can safely copy or move the tasks.db file to backup your tasks or transfer them to another computer.

System Tray

OD.Planner minimizes to the system tray. Alarms and midnight rollovers continue to work while the application is in the background.

Window Behavior

  • The window remembers its position and size between sessions
  • On first launch, it docks to the top-right of the primary screen
  • Double-click the header to maximize/restore

Building from Source

cd OD.Planner
dotnet build OD.Planner.slnx -c Release
