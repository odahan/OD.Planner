OD.Planner

Version 1.3.0 - Manuel d'utilisation

Introduction

OD.Planner est un gestionnaire de tâches léger et natif pour Windows, développé avec WPF et .NET. Il garde votre liste de tâches à portée de main dans une petite fenêtre toujours prête et s'assure que les échéances ne passent pas inaperçues — avec des alarmes sonores et une priorité par code couleur.

Premiers pas

Premier lancement

Lors du premier lancement d'OD.Planner, vous êtes invité à choisir où stocker votre base de données de tâches. Par défaut, elle est créée à côté de l'exécutable de l'application. Vous pouvez modifier cet emplacement ultérieurement dans les Paramètres.

Fenêtre principale

La fenêtre principale affiche votre liste de tâches avec :

  • Un menu déroulant de filtrage par catégorie pour n'afficher que les tâches d'une catégorie spécifique
  • Une case à cocher pour afficher/masquer les tâches terminées
  • un bouton "Ajouter" pour créer de nouvelles tâches

Gestion des tâches

Créer une tâche

Cliquez sur le bouton Ajouter ou appuyez sur Ctrl+N pour créer une nouvelle tâche. Vous serez invité à saisir :

  • Titre - La description de la tâche (obligatoire)
  • Catégorie - Catégorie optionnelle pour l'organisation
  • Priorité - Faible, Moyenne, Urgente ou Très urgente
  • Échéance - Aucune, X jours après la création, ou une date fixe

Modifier une tâche

Sélectionnez une tâche et appuyez sur F2 ou cliquez sur le bouton modifier pour la modifier.

Terminer une tâche

Cliquez sur la case à cocher à côté d'une tâche pour la marquer comme terminée. Les tâches terminées peuvent être masquées à l'aide de la case à cocher "Terminées".

Supprimer une tâche

Cliquez sur le bouton supprimer à côté d'une tâche. Une confirmation vous sera demandée.

Raccourcis clavier

RaccourciAction
Ctrl+NNouvelle tâche
F2Modifier la tâche sélectionnée

Échéances et alarmes

Types d'échéance

  • Aucune - Pas d'échéance pour cette tâche
  • Jours après création - L'échéance est à X jours après la création de la tâche
  • Date fixe - L'échéance est une date spécifique

Reporter les échéances

Chaque tâche avec échéance affiche des boutons +1j et +1sem pour reporter l'échéance d'un jour ou d'une semaine.

Niveaux d'alarme

NiveauDéclencheurIndicateur
Attention (J-1)1 jour avant l'échéancePastille jaune
Échéance (J0)Le jour de l'échéancePastille orange
En retardAprès l'échéancePastille rouge + clignotement

Popups d'alarme

Lorsqu'une alarme se déclenche, un popup apparaît avec les options suivantes :

  • Snooze 1h - Faire taire l'alarme pendant 1 heure
  • Arrêter - Désactiver l'alarme définitivement

Catégories

Les catégories vous aident à organiser vos tâches. Vous pouvez créer, renommer et supprimer des catégories dans la fenêtre des Paramètres.

Catégories par défaut : Travail et Personnel.

Paramètres

Cliquez sur l'engrenage pour ouvrir les Paramètres. Options disponibles :

Apparence

  • Thème sombre - Basculer entre les thèmes clair et sombre
  • Afficher les tâches terminées - Basculer la visibilité des tâches terminées
  • Réduire les animations - Désactiver les animations de clignotement pour l'accessibilité

Alarmes sonores

  • Activer les alarmes sonores - Interrupteur général pour toutes les alertes sonores
  • Alerte J-1 - Alerte sonore la veille de l'échéance
  • Alerte J0 - Alerte sonore le jour de l'échéance
  • Alerte de retard - Alerte sonore quand l'échéance est dépassée

Système

  • Démarrer avec Windows - Lancer OD.Planner au démarrage du système

Base de données

Modifier l'emplacement de votre fichier de base de données de tâches. L'application utilisera le nouvel emplacement après redémarrage.

Stockage des données

Les tâches sont stockées dans une base de données SQLite (tasks.db). Les paramètres sont enregistrés sous settings.json. Les deux fichiers sont situés à côté de l'application par défaut, ou sous %LOCALAPPDATA%\OD.Planner si le dossier de l'application n'est pas accessible en écriture.

Note : Vous pouvez copier ou déplacer le fichier tasks.db en toute sécurité pour sauvegarder vos tâches ou les transférer vers un autre ordinateur.

Zone de notification

OD.Planner se minimise dans la zone de notification. Les alarmes et les passages de minuit continuent de fonctionner lorsque l'application est en arrière-plan.

Comportement de la fenêtre

  • La fenêtre mémorise sa position et sa taille entre les sessions
  • Au premier lancement, elle s'ancre en haut à droite de l'écran principal
  • Double-cliquez sur l'en-tête pour maximiser/restaurer

Compilation depuis les sources

Prérequis : Windows 10+, SDK .NET 10

git clone https://github.com/odahan/OD.Planner.git
cd OD.Planner
dotnet build OD.Planner.slnx -c Release
